This repo helps you quickly install Oh My Zsh, a popular Zsh configuration manager. It automates most of the setup to ease your shell environment configuration.

### Key Features
- Automated Oh My Zsh installation
- Pre-configured with default settings
- Minimal dependencies

### Tech Stack
- Shell scripting (Bash/Zsh)
- Standard Unix command-line tools

### Getting Started

**Prerequisites**
- Zsh shell installed
- Curl or wget to fetch scripts

**Installation Steps**

```bash
# Clone the repository
git clone https://github.com/justin-napolitano/oh-my-zsh-install.git
cd oh-my-zsh-install

# Execute the installation script
./install.sh
```

**Gotchas**
- Ensure you have Zsh installed before running the script.
- Adjust any permissions if you run into issues with executing `install.sh`.
